# Tutorials

These tutorials are practical walkthroughs built around the actual repository structure.

## In-repo tutorial app

The monorepo contains a working frontend tutorial under `tutorial/`.

It currently demonstrates:

1. connect a wallet;
2. instantiate `VeraxSdk`;
3. compute or create a schema;
4. deploy a default portal;
5. issue an attestation;
6. fetch the attestation back.

Supported tutorial networks in source are:

- Linea Sepolia
- Arbitrum Sepolia
- Base Sepolia
- BSC Testnet
