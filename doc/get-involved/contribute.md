# Contribute

Verax is maintained in this monorepo. For code and documentation changes, treat this repository as the main source of
truth.

## Where to contribute

- product, contracts, SDK, explorer, tutorial, subgraph: this repository;
- documentation published through GitBook: the `doc/` folder in this repository;
- governance discussion: the community forum.

## Typical contribution paths

- open issues for bugs or missing features;
- submit PRs for code, tests, docs, or examples;
- improve schema, portal, module, or explorer discoverability;
- help tighten examples and tutorials against the actual source tree.

## Documentation contributions

For documentation work:

1. edit files under `doc/`;
2. keep examples aligned with contracts, SDK exports, explorer behavior, and subgraph schema;
3. prefer the monorepo over older parallel documentation repos or stale external tutorials.

## Useful contribution targets

- more end-to-end tutorials;
- better research notes on attestation semantics and trust;
- additional standard-library module docs;
- docs that explain how to operate a full custom Verax deployment.

## Contact

If you are unsure where a change belongs, use the channels listed in [Get in Touch](get-in-touch.md).
